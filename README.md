# J Agent

J Agent is a desktop AI workspace for long-running agent tasks, local tools, plugins, and editable workbench artifacts.

## Product

- Work with Javis in persistent task conversations
- Use local tools, Skills, MCP integrations, and product plugins
- Review files, presentations, documents, spreadsheets, terminals, and browser results in Workbench
- Keep model credentials and runtime data under the user's control

Download J Agent at [j.deeptoai.com](https://j.deeptoai.com/).
